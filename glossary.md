# Remmogo Project Glossary

| Term | Definition |
|---|---|
| Stakeholder | A person or organisation affected by the system. |
| Requirement | A capability or constraint that the system must satisfy. |
| System Boundary | The separation between functions performed by Remmogo and activities that occur outside the system. |
| Student | A University of Botswana student who uses Remmogo through a valid account. |
| Customer | A Student who requests to rent an item. |
| Owner | A Student who lists an item for rent. |
| Administrator | An authorised user who manages account issues and generates reports. |
| Item Listing | The information published by an Owner about an item offered for rent, including its category, condition, description, price and available quantity. |
| Rental Transaction | The system record of an agreement between a Customer and Owner to rent an item for a defined period. |
| Available | An item status indicating that at least one unreserved unit is available for rent. |
| Reserved | A status indicating that an item has been allocated to a pending rental transaction and must not be shown as available to another Customer. |
| Active | A rental status indicating that payment and handover have been confirmed and the rental period has started. |
| Completed | A rental status indicating that the item was returned and the required return confirmations were recorded. |
| Cancelled | A rental status indicating that the transaction ended before completion. |
| Overdue | A rental status indicating that the return date passed before the item’s return was confirmed. |
| Payment Confirmation | A record that the Customer or Owner confirmed an external payment. Remmogo does not process or hold the payment. |
| Return Confirmation | A record that a Customer or Owner confirmed the return of a rented item. |
| Rating | Feedback submitted by one rental participant about the other after a completed rental transaction. |
| Report | A record used for administrative review, including summaries of user activity, rental transactions or disputes. |
