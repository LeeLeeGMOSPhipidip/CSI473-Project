Selected Framework
Remmogo system will use Node.js together with Express.js for backend development and MySQL for data storage. We chose Node.js with Express.js because it is lightweight, easy to learn and we are familiar with MySQL.

Reasons for the Decision
Supports the Three-Tier Architecture selected for the project.
Integrates well with MySQL databases.
Has a large developer community and documentation.

The project will use npm (Node Package Manager) to manage external libraries and project dependencies.
Examples of dependencies include:
Node.js
Express.js
MySQL2
jsonwebtoken

Positive Consequences
Faster development.
Easy installation of project libraries.
Large amount of community support.
Good integration with web technologies.

Negative Consequences
Dependencies must be updated regularly.
Some third-party packages may introduce security vulnerabilities if not maintained.
