*Functional Requirements*

The system shall allow users to register and create an account using a valid UB email address.
The system shall allow registered users to sign in and sign out securely.
The system shall allow sellers to upload and list items for rent.
Each item listing shall include:
  Item name
  Category
  Condition
  Description
  Rental price
  Available quantity
The system shall require each item to be assigned to a category.
The system shall provide a search function that allows users to find listed items.
The storefront shall display only items that are currently available for rent.
The system shall allow the seller and renter to confirm that payment has been made.
At the end of the rental period, the system shall require both the seller and renter to confirm that the item has been returned.
The system shall allow sellers and renters to rate each other after a completed rental transaction.
The system shall update and display the available quantity of each item.
The system shall provide a chat function that allows sellers and renters to communicate.
The system shall allow administrators to manage account-related issues and generate various reports.
