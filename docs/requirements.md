# Remmogo Functional Requirements

## Account access

**FR-01 - Account registration**  
The system shall allow users to register and create an account using a valid University of Botswana email address.

**FR-02 - Sign in and sign out**  
The system shall allow registered users to sign in and sign out securely.

## Item listings

**FR-03 - List items for rent**  
The system shall allow Owners to upload and list items for rent.

**FR-04 - Item listing information**  
Each item listing shall include:

- Item name
- Category
- Condition
- Description
- Rental price
- Available quantity

**FR-05 - Item categories**  
The system shall require each item to be assigned to a category.

**FR-06 - Item search**  
The system shall provide a search function that allows users to find listed items.

**FR-07 - Available items**  
The storefront shall display only items that are currently available for rent, excluding reserved items.

## Rental transactions

**FR-08 - Payment confirmation**  
The system shall allow the Owner and Customer to confirm that payment has been made.

**FR-09 - Return confirmation**  
At the end of the rental period, the system shall require both the Owner and Customer to confirm that the item has been returned.

**FR-10 - Ratings**  
The system shall allow Owners and Customers to rate each other after a completed rental transaction.

**FR-11 - Available quantity**  
The system shall update and display the available quantity of each item.

**FR-12 - Chat**  
The system shall provide a chat function that allows Owners and Customers to communicate.

## Administration

**FR-13 - Account management and reporting**  
The system shall allow Administrators to manage account-related issues and generate reports.
