# Usability Test Report

### 1. Purpose
The purpose of this usability test is to evaluate whether University of Botswana students can use the Student Rental Marketplace easily to find items, request rentals, upload proof of payment, and understand rental status and return dates.

### 2. Test Objectives
The test aims to determine whether users can:
- Find an available item using search and categories.
- Understand item details, rental prices, and availability.
- Complete the steps required to request a rental.
- Locate the proof-of-payment upload function.
- Identify the rental due date and return-confirmation process.
- Understand system notifications and error messages.

### 3. Participants
The planned usability test involves five participants who represent potential users of the system.

| Participant | User type | Experience |

| P1 | Student renter | First-time user |
| P2 | Student renter | Basic web experience |

### 4. Test Environment
- System: Rremogo prototype.
- Device: Laptop or desktop computer.
- Browser: Google Chrome or another supported browser.
- Network: Internet or local development environment.
- Method: Task-based usability testing with observation.

### 5. Test Tasks

| Task ID | Task | Success criteria |
|---|---|---|
| T1 | Find an available fridge. | User locates an available fridge. |
| T2 | View an item's details. | User identifies its price, condition, and availability. |
| T3 | Request to rent an item. | User submits a rental request successfully. |
| T4 | Find the proof-of-payment upload option. | User identifies where payment proof is submitted. |
| T5 | Find the rental due date. | User correctly identifies the return date. |
| T6 | Confirm an item return. | User locates and completes the return-confirmation process, where available. |

### 7. Usability Measures

**Task completion rate**

Task completion rate = (Number of successfully completed tasks / Total tasks attempted) × 100

**Example:** If four out of five participants successfully complete a task, the completion rate is 80%. This is an example only, not a test result.

Other measures include:
- Time taken to complete each task.
- Number of errors or incorrect actions.
- Number of requests for assistance.
- Participant feedback and satisfaction.
