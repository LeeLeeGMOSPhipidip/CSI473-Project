# CSI473 Project

This repository contains the artefacts for the University of Botswana CSI473 Software Design team project.

## Team
- Ronald - Group leader
- Zanele
- Kgotla
- Leander

## Repository Structure

```
docs/          Project documentation
models/        UML and other design models
prototype/     UI prototypes and mock-ups
tests/         Test cases and validation
evidence/      Supporting evidence and research
decisions/     Design decision records
glossary.md    Project glossary
```

## Git Branches

- `main` – Stable version
- `staging` – group members contributions go here first
- `leander` – leander's branch
- `zanele/...` – zanele's branch
- `ronald`, ronald's branch
- `kgotla` – kgotla's branch

## Purpose

This repository is used to manage the CSI473 semester project and maintain all project artefacts under version control.
