## Git Branches

- `main` – Stable version
- `develop` – Integration branch
- `feature/...` – Individual features
- `lab-01`, `lab-02`, etc. – Laboratory work

## Purpose

This repository is used to manage the CSI473 semester project and maintain all project artefacts under version control.
